# PadelRent

Aplikasi berbasis web yang dibangun menggunakan **PHP** untuk pengelolaan dan pemesanan lapangan padel.

## Fitur Utama

- **Login Admin**: Autentikasi khusus pengelola sistem/admin.
- **CRUD Berita**: Pengelolaan informasi & artikel terkini seputar padel.
- **CRUD Raket**: Pengelolaan katalog & ketersediaan raket.
- **CRUD Booking**: Pengelolaan jadwal serta data pemesanan lapangan.
- **Integrasi WhatsApp**: Fitur direct chat ke WhatsApp untuk komunikasi/konfirmasi pemesanan.
